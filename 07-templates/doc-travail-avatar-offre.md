## B.3 — Test final : le no-brainer

Réponds honnêtement :

- [ ] Le prospect penserait-il que la valeur > le prix ?
- [ ] Toutes les objections de A.6 ont-elles un bonus associé ?
- [ ] Le risque est-il entièrement porté par moi ?
- [ ] Le mécanisme tient-il en une phrase ?
- [ ] Y a-t-il une raison crédible d'acheter **aujourd'hui** ?
- [ ] Le prospect se sentirait-il **bête de refuser** ?

Si une case n'est pas cochée → l'offre n'est pas prête.
