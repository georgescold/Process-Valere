## ⚠️ Les SPAM WORDS à éviter

**Règle : maximum 3 dans un même mail.** Les cumuler tue la délivrabilité.

### Formatage à risque
- TOUT EN MAJUSCULES
- Points d'exclamation excessifs (!!!)
- Emojis en excès

### Mots / expressions à risque
| Catégorie | Exemples |
|---|---|
| Argent | *free*, *gratuit*, *cash*, *fantastic income*, *earn money*, *no cost*, *100 % free* |
| Urgence forcée | *act now*, *buy now*, *urgent*, *dernière chance*, *offre limitée* |
| Sécurité / compte | *vérifiez votre compte*, *mise à jour*, *suspension*, *votre compte a été* |
| Superlatifs | *incroyable*, *garanti*, *risque zéro*, *miracle* |
| Mort / choc | *mort*, *décès* (⚠️ "%FIRSTNAME% est mort" = spam word) |

**Ce qui passe malgré tout :** *call now*, *click here* — dans un mail par ailleurs
propre. C'est le **cumul** qui déclenche le filtre, pas un mot isolé.

## Les 4 objectifs d'un email (rappel)

```
1. DÉLIVRER  → DNS paramétré + base filtrée + réputation
2. OUVRIR    → objet + EXPÉDITEUR
3. CLIQUER   → corps + CTA
4. ACHETER   → le système entier
```

## Heures d'envoi

| Fréquence | Créneaux |
|---|---|
| 1 mail/jour | Entre 16h et 20h30 |
| 2 mails/jour | Midi + soir |
| 3 mails/jour (jour de closing) | 16h + 20h/21h + 23h |

⚠️ Éviter 4h du matin. 18h heure de Paris = beaucoup de concurrence dans la boîte.
Tester 13h peut être payant.
