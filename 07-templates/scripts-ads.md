## Comment utiliser ces scripts avec la méthode 10×10×10

```
1. Prends les 3 scripts
2. Découpe chacun en HOOK / BODY / CLOSING
3. Écris 7 hooks supplémentaires (variations, angles différents)
4. Écris 7 bodies supplémentaires
5. Écris 7 closings supplémentaires
6. Monte chaque segment séparément
7. Combine → 1 000 créatives
```

**Où trouver les angles :** liste 20 à 50 bénéfices de ton produit.
Chaque bénéfice = un angle = un hook.
(Cf. `02-acquisition/facebook-ads.md` § Meta Andromeda)

## Checklist avant de publier une créative

- [ ] Hook fort dans les 3 premières secondes
- [ ] Dynamique / style TikTok
- [ ] Sous-titres
- [ ] Bénéfice clair
- [ ] Call to action explicite
- [ ] Format 9:16 (ou 1:1 si avatar 45+)
- [ ] Vitesse ×1,10
- [ ] Pas de promesse de gain sur un temps donné (compliance)
- [ ] Pas d'avant/après visuel non contourné (compliance)
- [ ] 5 textes primaires / 5 headlines / 5 descriptions renseignés
