## 1. Diminuer le CPA des ADS

*(pas dans un ordre de priorité — tout est à travailler)*

- [ ] Améliorer le **hook** / le copywriting
- [ ] Améliorer le **CTA**
- [ ] Faire une **variante bottom** (un élément en bas qui maintient l'attention)
- [ ] Faire des **variantes de différents hooks**
- [ ] Faire des ads à **différents niveaux d'awareness** dans le funnel d'ads
      (faire passer le prospect de *unaware* à *most aware*)
- [ ] Améliorer le **targeting**
- [ ] Améliorer l'**ad copy**
- [ ] Travailler les **audiences de retargeting**

**Idées :**
- Look-alike audiences (LAL)
- Retarget les *clickers* dans une audience dédiée, et les exclure de l'audience
  principale *(de l'optimisation fine — pas prioritaire)*
- **Comprendre en profondeur POURQUOI une créative performe.**
  Qu'est-ce que ça déclenche chez le prospect ? Pourquoi ?

> C'est le travail **quotidien** du media buyer + de l'ad manager.

---

## 2. Augmenter la conversion de la Landing Page

- [ ] A/B test **headline**
- [ ] A/B test **headline du pop-up de sortie**
- [ ] A/B test **CTA**
- [ ] **Simplifier le design** (souvent, moins = mieux)
- [ ] Copywriting général
- [ ] **Scroll tracking**
- [ ] **Retargeting pixel**

**Sur le scroll :** si la personne n'a pas besoin de scroller (mobile) pour
atteindre le bouton, tu gagnes en conversion.
Astuce inverse : mettre un trigger visuel en bas (Lamborghini, argent) qui donne
envie de scroller → augmente le taux de conversion.

**Sur le retargeting pixel :** retarget les non-opt-in directement sur la VSL,
ou les opt-in sur la VSL.

> La LP est la partie la plus facile à optimiser du funnel. Cible : ~50 % de conversion.

---

## 3. Augmenter le CTR de la VSL

*(taux de clic sur le bouton depuis la page de vente)*

- [ ] **A/B test headline** ⭐ trop peu de gens le font. C'est l'étape n°1.
- [ ] A/B test **thumbnail** (miniature de la vidéo)
- [ ] A/B test **sub-headline**
- [ ] **Teasing depuis la LP / la créative** — si tu teases la VSL dans la landing
      page, la personne clique plus souvent sur la vidéo
- [ ] Copywriting général
- [ ] Ajouter des preuves sous la vidéo

**Idée :** retarget les non-clickers sur la **même VSL avec une headline différente**.

> C'est le levier le plus rentable du funnel. Mettre 1 € en pub, en ressortir 1 €
> suffit à savoir qu'on sera rentable à long terme — parce qu'il n'y a plus qu'à
> améliorer la headline, la thumbnail, la sub-headline.

---

## 4. Augmenter la conversion de la VSL

*C'est le travail de l'optimizer. Le plus gros chantier.*

- [ ] **Hook power** — rétention des 3 premières secondes
- [ ] **Rétention globale**
- [ ] **Couper là où il y a un drop de rétention**
- [ ] **Couper les moments inutiles** (une phrase qui ne sert à rien → cut)
- [ ] **Preuve précoce du bénéfice**
- [ ] Script / copywriting général (structure)
- [ ] **ÉNORME garantie — risk reversal** (faire en sorte que ce soit toi qui
      prennes le risque, pas le client)
- [ ] **Meilleures preuves sociales**
      *(vidéo > image ; célébrité > anonyme ; proche > inconnu)*
- [ ] Vérifier que la **traduction** est parfaite (si multi-marché)
- [ ] **Les objections peuvent-elles être mieux traitées ?**
- [ ] A/B test **hooks**
- [ ] A/B test **leads**
- [ ] A/B test **preuves sociales**
- [ ] A/B test **scarcity / urgence**
- [ ] **Agressivité du CTA**
- [ ] **Image du gourou** / visuel / proximité avec le prospect

**Idées :**
- Toujours avoir un œil sur les stats de l'hébergeur vidéo (Wistia)
- **Tracker toutes les stats tous les jours**
- Compréhension profonde du système
- Utiliser un modèle de raisonnement (ChatGPT o1 ou équivalent) pour l'analyse
  de data
- **Copier ce qui marche le mieux sur tes autres VSL** — testé une fois, appliqué
  partout (ex : le décompte "5, 4, 3, 2, 1" en ouverture augmente le watch time)

---

## 5. Augmenter la conversion du checkout (bon de commande)

- [ ] Rappeler clairement les **bénéfices**
- [ ] **Preuves sociales**
- [ ] **Urgence / rareté**
- [ ] Rappeler la **sécurité du formulaire**
- [ ] Mettre en avant les **bonus**
- [ ] Mettre en avant l'**énorme promotion**
- [ ] Mettre en avant la **politique de remboursement**
- [ ] **Images de qualité / brandées**
- [ ] **Exit pop-up avec promotion** ⭐ (très efficace sur desktop)
- [ ] **Devise locale** (critique en Amérique latine)
- [ ] **Résumé de la commande** avec tous les bonus
- [ ] **Q&A** en bas, avant les CGV
- [ ] **Témoignages**
- [ ] **Pop-up d'activation** quand d'autres personnes achètent

**Idée :** retarget les personnes qui se sont arrêtées au checkout.

---

## 6. Augmenter l'EPC du bump

⚠️ **Métrique = EPC, pas taux de conversion.**
(Sinon on mettrait le bump à 1 € et invisible.)

- [ ] A/B test **headline**
- [ ] Meilleur **copy**
- [ ] Meilleure **offre**
- [ ] **Scarcity**
- [ ] ⭐ **Pré-cocher le bump** — gain instantané
- [ ] A/B test **offres**
- [ ] A/B test **prix**

**Idées :**
- Tracker le revenu exact du bump (pas si simple à mettre en place)
- **Ajouter un 2e, 3e, 4e bump** — est-ce que ça monte l'EPC global ?

**Objectif du bump :** *"décision facile, ce bump est un no-brainer."*

---

## Comment aborder l'optimisation au quotidien

```
1. Tracker TOUTES les stats, TOUS les jours
2. Identifier la métrique la plus faible du funnel
3. Lister les hypothèses d'amélioration
4. A/B tester UNE variable à la fois
5. Garder ce qui gagne, itérer
```

> "Passe 20-25 h par jour pendant 6 mois, 1 an, 2 ans, 5 ans, 10 ans dessus
> jusqu'à avoir une VSL qui fait 40 000 € par jour et 100 millions de revenus
> sur une seule et même VSL."

C'est le vrai métier. Tout le reste est du one-shot.

## Ordre de priorité si tu ne sais pas par où commencer

```
1. La HEADLINE de la VSL        ← 30 secondes de travail, plus gros levier
2. Le LEAD de la VSL            ← vrai travail, gros impact
3. Les CRÉATIVES                ← le 20/80 du CPA
4. Le BUMP pré-coché            ← gain instantané, 5 minutes
5. L'UPSELL (s'il n'existe pas) ← gain instantané
6. La séquence EMAIL 7 jours    ← là où est le profit net
7. Le reste
```
