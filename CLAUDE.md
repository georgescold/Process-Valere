# Process Infoproduit — Base de connaissance

## Ce que c'est

Base de connaissance issue de **Business OS (The Valere)**, structurée pour permettre
la **création automatisée de funnels infoproduit** — de l'ad copy jusqu'à l'offre.

Source : formation Business OS (modules "Les bases" + lives). Un praticien qui a spend
5-6M€ sur ses propres funnels et dépassé 100M€ de CA sur un business.

## Comment répondre aux questions

1. **Toujours répondre en français**, ton direct, pas de langue de bois.
2. **Chercher d'abord dans les fichiers de ce dossier** avant de répondre de mémoire.
   La connaissance ici prime sur les généralités marketing.
3. Si la question porte sur **un process** → `06-process/PROCESS-MAITRE.md`
4. Si la question porte sur **du copy à écrire** → `03-marketing-copy/` + `07-templates/`
   → pour **auditer un texte déjà écrit** : `03-marketing-copy/10-questions.md`
5. Si la question porte sur **de la pub** → `02-acquisition/`
6. Si on demande **"optimise mon funnel"** → `05-funnel/optimisation-checklist.md`
   → si on demande **"audite ma page / ma VSL / ma créative"** → `05-funnel/teardowns.md`
7. Si la question porte sur **le scaling / l'équipe / la structure** → `08-scaling/`
8. Si la question porte sur **la vente par appel** (closing téléphonique, high
   ticket, objections, setting, closers) → `10-closing/`
   ⚠️ Ne jamais confondre avec le « closing » d'une VSL (= la fin du texte de
   vente) qui est dans `03-marketing-copy/vsl.md`
9. **Avant de répondre à toute question fermée** ("est-ce que je dois…", "low ou high ticket", "quel budget") → vérifier `09-faq/arbitrages.md`, la réponse y est peut-être déjà tranchée

## Les 4 lois non négociables

Ces règles écrasent toute autre considération. Si une réponse les viole, elle est fausse.

1. **Business = mettre le bon message devant la bonne personne au bon moment.**
   Message = marketing. Personne = acquisition. Moment = timing marché.
2. **Objectif unique : LTV ↑ , CPA ↓.** Toute tâche qui ne sert ni l'un ni l'autre
   n'a rien à faire dans la journée.
3. **La structure CEO (Blair Warren) est dans TOUT** : VSL, ads, emails, closing,
   séquences. Voir `03-marketing-copy/structure-ceo.md`.
4. **On vend un résultat + de l'urgence. Jamais un produit.**
   Marketing = ce que le marché *veut*. Produit = ce dont il *a besoin*.

## Vocabulaire maison

| Terme | Sens |
|---|---|
| **CPA** | Coût par achat |
| **LTV** | Lifetime value (revenu total par client) |
| **EPC** | Earning per click |
| **EPL** | Earning per lead |
| **Broad** | Ciblage = pays uniquement, zéro centre d'intérêt |
| **Lead** (copy) | Les 20 premiers % d'un texte de vente |
| **Lead** (traffic) | Un contact / email capturé |
| **Structure CEO** | Rêve → Échec → Peur → Doute → Ennemi (Blair Warren) |
| **Big Idea** | L'hypothèse narrative qui porte le mécanisme |
| **One Belief** | La croyance unique à installer : *cette nouvelle opportunité est la clé de ton désir, uniquement via mon mécanisme* |
| **Les 10 questions** | La grille d'audit d'un texte de vente — Q1 différence → Q10 coût de l'inaction |
| **Mécanisme** | Le pont du point A (douleur) au point B (résultat) |
| **Bump** | Offre additionnelle sur le bon de commande |
| **Advertorial** | Page de contenu type "top 5" qui pré-vend |
| **Closing** (copy) | Les 10-20 derniers % d'une VSL, après le 1er CTA. 27 outils, **3 maximum par texte** |
| **Big Domino** | La croyance unique qui, si elle tombe, fait tomber toutes les objections. = la One Belief |
| **Closing** (vente) | L'appel téléphonique qui vend une offre high ticket |
| **Le GAP** | L'écart situation actuelle → situation désirée. Ton offre est le pont. Équivalent du mécanisme en copy |
| **L'échelle 1-10** | La question pivot du closing : « es-tu sûr d'atteindre [RÉSULTAT SPÉCIFIQUE] avec moi ? ». < 10 = pas de prix |
| **R1 / R2** | Premier / second rendez-vous de vente. **On ne fait jamais de R2** |
| **Setting** | Qualification amont d'un appel : problème · finances · timing |
