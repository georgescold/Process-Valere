# Process Infoproduit — Base de connaissance

## Ce que c'est

Base de connaissance issue de **Business OS (The Valere)**, structurée pour permettre
la **création automatisée de funnels infoproduit** — de l'ad copy jusqu'à l'offre.

Source : formation Business OS — **la totalité** des transcripts : modules « Les
bases », les 27 lives, l'Atelier Organique, les Marketing Tips, les bonus membre
annuel et les 13 sessions de Q&A. Un praticien qui a spend 5-6M€ sur ses propres
funnels et dépassé 100M€ de CA sur un business.

⚠️ Le dossier `transcript business os/` contient les **sources brutes non traitées**
(195 fichiers, ~888 000 mots de transcription automatique). Il est versionné pour
archive, mais ce n'est **pas** la base de connaissance :

- ❌ **Ne jamais répondre à une question depuis un fichier de ce dossier** — la
  transcription est truffée d'erreurs de reconnaissance (« la vaisselle » = la VSL,
  « obsel » = upsell, « mediaabying » = media buying…).
- ❌ **Ne jamais le supprimer ni modifier ses `.txt`.**
- ✅ N'y revenir que pour vérifier une citation ou ingérer un passage manqué — et
  vérifier d'abord qu'il n'est pas déjà dans la base.

Voir `transcript business os/README.md`.

## Comment répondre aux questions

1. **Toujours répondre en français**, ton direct, pas de langue de bois.
2. **Chercher d'abord dans les fichiers de ce dossier** avant de répondre de mémoire.
   La connaissance ici prime sur les généralités marketing.
3. Si la question porte sur **un process** → `06-process/PROCESS-MAITRE.md`
   → pour **écrire** un process (déléguer, automatiser, sortir le fondateur de la
   boucle) : `06-process/creer-un-process.md`
4. Si la question porte sur **du copy à écrire** → `03-marketing-copy/` + `07-templates/`
   → pour **auditer un texte déjà écrit** : `03-marketing-copy/10-questions.md`
   → pour **produire des VSL en série** (SOP, mécanisme unique) : `03-marketing-copy/vsl-sop-production.md`
5. Si la question porte sur **de la pub** → `02-acquisition/`
   → **créatives image / statiques** : `02-acquisition/creatives-statiques.md`
   → **YouTube organique** (scripts, titres, miniatures, voix) : `02-acquisition/youtube.md`
   → **devenir affilié / media buyer pour d'autres** : `02-acquisition/affiliation.md` § Partie 2
6. Si on demande **"optimise mon funnel"** → `05-funnel/optimisation-checklist.md`
   → si on demande **"audite ma page / ma VSL / ma créative"** → `05-funnel/teardowns.md`
   → pour des **modèles de funnels qui tournent** : `05-funnel/funnels-gagnants.md`
   → pour les **upsells / OTO** : `05-funnel/upsells.md`
7. Si la question porte sur **le scaling / l'équipe / la structure** → `08-scaling/`
   → **recruter** (qui, dans quel ordre, quelles questions) : `08-scaling/recrutement.md`
   → **délivrer et faire monter la LTV** (CSM, back-end) : `08-scaling/delivrabilite-csm.md`
   → **productivité / dopamine / deep work** : `08-scaling/productivite.md`
8. Si la question porte sur **la vente par appel** (closing téléphonique, high
   ticket, objections, setting, closers) → `10-closing/`
   → pour **construire et scaler** le funnel qui remplit l'agenda : `10-closing/call-funnel.md`
   ⚠️ Ne jamais confondre avec le « closing » d'une VSL (= la fin du texte de
   vente) qui est dans `03-marketing-copy/vsl.md`
9. **Avant de répondre à toute question fermée** ("est-ce que je dois…", "low ou high ticket", "quel budget") → vérifier `09-faq/arbitrages.md`, la réponse y est peut-être déjà tranchée
10. Si la question porte sur **comment Valère pense / raisonne / décide** (arbitrages
   de vie, apprentissage, niveaux, priorités) → `01-principes/modele-mental.md`
11. Si la question porte sur **un lancement** (organique, sans pub) →
   `06-process/lancement-organique.md`
12. Si la question porte sur **le low ticket vers le high ticket** →
   `04-produit/low-to-high-ticket.md`

## Les 4 lois non négociables

Ces règles écrasent toute autre considération. Si une réponse les viole, elle est fausse.

1. **Business = mettre le bon message devant la bonne personne au bon moment.**
   Message = marketing. Personne = acquisition. Moment = timing marché.
2. **Objectif unique : LTV ↑ , CPA ↓.** Toute tâche qui ne sert ni l'un ni l'autre
   n'a rien à faire dans la journée.
   → Les leviers : `01-principes/strategie-unique.md`
3. **La structure CEO (Blair Warren) est dans TOUT** : VSL, ads, emails, closing,
   séquences. Voir `03-marketing-copy/structure-ceo.md`.
4. **On vend un résultat + de l'urgence. Jamais un produit.**
   Marketing = ce que le marché *veut*. Produit = ce dont il *a besoin*.

## Vocabulaire maison

| Terme | Sens |
|---|---|
| **CPA** | Coût par achat *(= CAC, Cost of Acquisition of a Customer)* |
| **Unfair advantage** | L'assemblage de leviers LTV/CAC que personne d'autre ne fait dans ta niche |
| **Scaling à BE** | Scaler à break-even voire en perte sur J+1, en pariant sur la LTV à 30-60 jours |
| **LTV** | Lifetime value (revenu total par client) |
| **EPC** | Earning per click |
| **EPL** | Earning per lead |
| **Broad** | Ciblage = pays uniquement, zéro centre d'intérêt |
| **Lead** (copy) | Les 20 premiers % d'un texte de vente |
| **Lead** (traffic) | Un contact / email capturé |
| **Structure CEO** | Rêve → Échec → Peur → Doute → Ennemi (Blair Warren) |
| **Big Idea** | L'hypothèse narrative qui porte le mécanisme |
| **One Belief** | La croyance unique à installer : *cette nouvelle opportunité est la clé de ton désir, uniquement via mon mécanisme* |
| **Les 10 questions** | La grille d'audit d'un texte de vente — Q1 différence → Q10 coût de l'inaction |
| **Mécanisme** | Le pont du point A (douleur) au point B (résultat) |
| **Bump** | Offre additionnelle sur le bon de commande |
| **Advertorial** | Page de contenu type "top 5" qui pré-vend |
| **Closing** (copy) | Les 10-20 derniers % d'une VSL, après le 1er CTA. 27 outils, **3 maximum par texte** |
| **Big Domino** | La croyance unique qui, si elle tombe, fait tomber toutes les objections. = la One Belief |
| **Closing** (vente) | L'appel téléphonique qui vend une offre high ticket |
| **Le GAP** | L'écart situation actuelle → situation désirée. Ton offre est le pont. Équivalent du mécanisme en copy |
| **L'échelle 1-10** | La question pivot du closing : « es-tu sûr d'atteindre [RÉSULTAT SPÉCIFIQUE] avec moi ? ». < 10 = pas de prix |
| **R1 / R2** | Premier / second rendez-vous de vente. **On ne fait jamais de R2** |
| **Setting** | Qualification amont d'un appel : problème · finances · timing |
| **CPL** | Coût par lead = CPC ÷ taux de conversion de la LP. La vraie métrique amont |
| **Cash collected** | Le cash réellement encaissé à J+0. **≥ 40-50 % du contrat**, sinon le funnel ne tient pas |
| **OTO** | *One Time Offer* — un upsell présenté une seule fois après l'achat. Pricing **décroissant** |
| **Bridge** | Page de transition type « top 3 » entre l'ad et l'offre. Très peu utilisée en France |
| **A player / B player** | 10/10 vs moyen dans son domaine. On met des A players **uniquement** sur les postes qui rapportent |
| **Killer question** | La question chiffrée d'un formulaire de recrutement qui fait tout le tri |
| **VSL de recrutement** | Une VSL dont le CTA est « postule ». Le canal n°1 pour trouver des A players |
| **CSM** | *Customer Success Manager* — délivre le produit et fait monter la LTV. Connecteur ou expert |
| **Point d'activation** | Le moment où un client obtient son premier résultat. Se définit **à rebours** |
| **Source of Truth** | La base (Airtable) qui centralise tout ce que l'équipe sait d'un client |
| **Déclencheur** | La condition écrite dans un process qui retire le fondateur de la boucle |
| **Cycle de l'oseille** | Semer (contenu) → nourrir (low ticket) → récolter (high ticket). 3 funnels, zéro waste |
| **Compte avatar** | Un compte social neuf consommé **comme ton avatar**, 20-50 min/semaine, pour calibrer ton algorithme |
| **Ramp-up** | Les 4 semaines de montée en compétence d'une recrue, payées **à la fin** |
| **Marketing bourrin** | Marketing agressif. Obligatoire en océan rouge, contre-productif en océan bleu |
