# PROCESS MAÎTRE — Créer un funnel infoproduit de A à Z

> Le pipeline complet, de la décision stratégique jusqu'à l'optimisation.
> **Ordre non négociable.** Chaque phase produit les inputs de la suivante.

```
PHASE 0  ─ STRATÉGIE          ─ 1 jour
PHASE 1  ─ FONDATION          ─ 2-3 jours   (Avatar + Offre + Mécanisme)
PHASE 2  ─ MESSAGE            ─ 3-5 jours   (VSL + pages)
PHASE 3  ─ TECHNIQUE          ─ 2 jours     (Funnel build + pixels)
PHASE 4  ─ ACQUISITION        ─ 3-5 jours   (Créatives + lancement)
PHASE 5  ─ BACKEND            ─ 2 jours     (Emailing)
PHASE 6  ─ OPTIMISATION       ─ ∞
```

---

# ═══ PHASE 0 — STRATÉGIE ═══

## 0.1 — Choisir la niche

- [ ] **Grosse niche**, pas micro-niche (make money, perte de poids, spiritualité,
      investissement, relations)
- [ ] Le problème résolu est-il **profond** (survie / reproduction) ?
- [ ] Y a-t-il des concurrents qui font de l'argent ? *(oui = bon signe)*

> 📖 `01-principes/principes-premiers.md`

## 0.2 — Choisir le canal d'acquisition

| Ton profil | Canal |
|---|---|
| Pas de budget, du temps | Organique (shorts + X) → Telegram → YouTube |
| Budget ≥ 30-50 €/jour | Facebook Ads |
| Intention de recherche forte (SaaS B2B) | Google Ads |
| Déjà une audience | Organique + emailing |

> 📖 `02-acquisition/facebook-ads.md` · `02-acquisition/organique.md`

## 0.3 — Déterminer l'awareness du trafic

☐ Unaware ☐ Problem aware ☐ Solution aware ☐ Product aware ☐ Most aware

⚠️ **Ça change intégralement le texte.** Trafic froid (pub) et trafic chaud
(ton audience) = deux VSL différentes pour le même produit.

## 0.4 — Choisir le format d'offre

☐ DIY (< 100 €/mois) ☐ DWY (2 500 - 4 000 €) ☐ DFY (10 000 - 20 000 €)

Ou **architecture recommandée** : entrée 7 € (ou gratuit) → high ticket au call.

> 📖 `04-produit/formats-offre.md`

**✅ Livrable Phase 0 :** niche + canal + awareness + format, écrits noir sur blanc.

# ═══ PHASE 1 — FONDATION ═══

> **On ne lance AUCUN business sans faire cette phase.**
> Template à dupliquer : `07-templates/doc-travail-avatar-offre.md`

## 1.1 — Fiche produit (partir de SOI)

Paradigme inversé : ne pars pas de l'avatar. Pars de **ce que tu veux vendre**,
puis construis l'avatar autour.

- [ ] Qu'est-ce que je vends exactement ?
- [ ] À qui ?
- [ ] À quel prix ?
- [ ] Quel résultat je garantis ?

## 1.2 — L'AVATAR

Utiliser le prompt IA en 4 étapes (`07-templates/prompts-ia.md` § 1)
**puis** remplir manuellement le doc de travail.

À produire impérativement :
- [ ] **La matrice** : Frustrations / Désirs / Peurs / Rêves
- [ ] Fiche socio-démographique
- [ ] Recherche concurrence
- [ ] **L'ENNEMI COMMUN**
- [ ] **Liste des OBJECTIONS** (toutes)
- [ ] **Liste de 20 à 50 BÉNÉFICES** ← ce sont tes angles marketing pour la Phase 4
- [ ] Preuves disponibles

⚠️ Distinguer désir de surface / désir profond. On vend le profond.

> 📖 `03-marketing-copy/avatar-et-offre.md`

## 1.3 — BIG IDEA + MÉCANISME

- [ ] **Big Idea** = l'hypothèse narrative qui porte le mécanisme
- [ ] **Mécanisme** = le pont A → B, en **3 étapes maximum**
- [ ] Test : le mécanisme tient-il en une phrase ? Est-il simple ? rapide ? clair ?

## 1.4 — L'OFFRE (les 8 composantes)

- [ ] 1. Packaging
- [ ] 2. Valeur perçue (value stacking chiffré)
- [ ] 3. Garantie / risk reversal
- [ ] 4. Preuve du résultat
- [ ] 5. Urgence / rareté **+ justification de l'urgence**
- [ ] 6. Mécanisme
- [ ] 7. ⭐ **Un bonus par objection** listée en 1.2
- [ ] 8. Réduction / ancrage de prix

**Test final :** le prospect se sentirait-il **bête de refuser** ?
Si non → l'offre n'est pas prête.

## 1.5 — Le MVP produit

⚠️ **Ne construis pas le produit complet maintenant.**

- [ ] MVP = 1 pain point → 1 mécanisme → 1 résultat
- [ ] Le strict minimum qui tient la promesse
- [ ] Version complète **après** validation du marché

> 📖 `04-produit/philosophie-produit.md`

**✅ Livrable Phase 1 :** doc avatar + offre complet, mécanisme en 3 étapes, MVP défini.

# ═══ PHASE 2 — LE MESSAGE ═══

## 2.1 — Choisir le type de lead

Parmi les 10 (`07-templates/leads-10-types.md`), selon :
- ton style
- ta Big Idea
- l'awareness (Phase 0.3)

Si tu débutes : **Problem-Solution** ou **Testimonial**.

## 2.2 — Écrire la HEADLINE + SUB-HEADLINE

Checklist :
- [ ] Claire et précise
- [ ] Bénéfice
- [ ] Curiosité
- [ ] Spécifique
- [ ] Urgence
- [ ] Simple

Format :
```
H1 : [BÉNÉFICE] + [SANS DOULEUR] + [DÉLAI]
H2 : Découvrez comment [MÉCANISME NOMMÉ] permet de [PROMESSE].
```

## 2.3 — Écrire la VSL

```
LEAD (20 %)      → hook + curiosité + bénéfice. Objectif : qu'il RESTE
BODY (60-70 %)   → structure CEO en 11 blocs
CLOSING (10-20 %) → 3 outils max + Always Be Leaving
```

**Le body, bloc par bloc :**
- [ ] 1. Rêves *(visualisation, émotion, possibilité, amplification)*
- [ ] 2. Échecs *("ce n'est pas ta faute")*
- [ ] 3. Peur *(pire scénario, douleur présente, coût de l'inaction)*
- [ ] 4. Ennemi commun *(Us vs Them, polarisation)*
- [ ] 5. Doutes *(confirmer + lever les objections)*
- [ ] 6. Preuve + Big Idea
- [ ] 7. Mécanisme *(3 étapes, simple/rapide/clair)*
- [ ] 8. Bénéfice + preuve + rêve *(escalier de l'imagination)*
- [ ] 9. Urgence
- [ ] 10. Garantie
- [ ] 11. CTA

> 📖 `03-marketing-copy/structure-ceo.md` · `03-marketing-copy/body-detaille.md`
> 📖 `03-marketing-copy/vsl.md` · ⭐ `03-marketing-copy/headline-hook-bigidea.md`

## 2.4 — Audit du texte (biais cognitifs)

- [ ] Rareté · [ ] Urgence · [ ] Preuve sociale · [ ] Ancrage
- [ ] Autorité · [ ] Aversion à la perte · [ ] Confirmation
- [ ] Cadrage positif de tous les chiffres · [ ] Réciprocité · [ ] Appartenance

> 📖 `03-marketing-copy/biais-cognitifs.md`

## 2.5 — Audit vocabulaire

- [ ] Zéro "apprendre" / "découvrir" → **révéler**, **dévoiler**
- [ ] Zéro "formation" / "produit" → **transformation**, **système**
- [ ] Zéro caractéristique → **bénéfices uniquement**
- [ ] Zéro négation dans les promesses
- [ ] Image mentale + mot d'émotion partout
- [ ] Une phrase = une idée

## 2.6 — Écrire les autres pages

- [ ] **Landing page** (si applicable) → choisir parmi les **6 structures** :
      `05-funnel/landing-pages.md`
- [ ] **Bon de commande** : bénéfices, preuves, urgence, sécurité, bonus,
      remboursement, résumé, Q&A, témoignages
- [ ] **Le BUMP** : "décision facile, no-brainer" — **pré-coché**
- [ ] **L'UPSELL** : ~10 % du prix principal
- [ ] **Thank you page** : elle vend aussi

> 📖 `05-funnel/anatomie-funnel.md`

**✅ Livrable Phase 2 :** VSL complète + toutes les pages écrites.

# ═══ PHASE 3 — TECHNIQUE ═══

## 3.1 — Setup Facebook (à faire EN AMONT, ça prend du temps)

- [ ] Navigateur anti-détection (Dolphin Anty / Incogniton)
- [ ] Proxy résidentiel dédié par profil
- [ ] 3 profils : 2 admins + 1 employé
- [ ] BM créé, **attendre 24 h**
- [ ] Warm-up : campagne Page Like à 5 $/jour
- [ ] Vérifier manuellement le premier paiement
- [ ] Page créée depuis un profil indépendant
- [ ] Ad account (agence de préférence)
- [ ] Moyen de paiement fiable (⚠️ pas de banque FR traditionnelle)

> 📖 `02-acquisition/setup-anti-ban.md`

## 3.2 — Construire le funnel

- [ ] Systeme.io (ou ClickFunnels)
- [ ] Toutes les pages montées
- [ ] Vidéo hébergée sur **Wistia / Vimeo** (jamais YouTube)
- [ ] Sous-titres sur la vidéo
- [ ] ❌ Watermark de l'outil retirée
- [ ] CGV + mentions légales
- [ ] Bump **pré-coché** (code)
- [ ] iClosed si high ticket

## 3.3 — Installer les pixels

```
Landing Page     →  PageView
VSL              →  Lead
Bon de commande  →  InitiateCheckout
Thank you page   →  Purchase
```

- [ ] Pixel créé, code dans le `<head>` de chaque page
- [ ] Événement adapté page par page
- [ ] Vérifié avec **Meta Pixel Helper**
- [ ] **Si high ticket** : Typeform de qualification + 2 thank you pages
      (une avec pixel pour les qualifiés, une sans pour les autres)

> 📖 `02-acquisition/facebook-ads.md` § Le Pixel

**✅ Livrable Phase 3 :** funnel en ligne, pixels vérifiés, compte pub prêt.

# ═══ PHASE 4 — ACQUISITION ═══

## 4.1 — Générer les angles

- [ ] Reprendre les **20-50 bénéfices** de la Phase 1.2
- [ ] Un bénéfice = un angle = une créative
      *(avec Andromeda, Facebook crée les sous-audiences tout seul)*

## 4.2 — Produire les créatives (méthode 10×10×10)

```
1. Écrire 10 HOOKS      (un par angle)
2. Écrire 10 BODIES
3. Écrire 10 CLOSINGS
4. Monter chaque segment séparément
5. Combiner → 1 000 créatives possibles
```

- [ ] Base : les 3 scripts de `07-templates/scripts-ads.md`
- [ ] Format 9:16 (ou 1:1 si avatar 45+)
- [ ] Sous-titres
- [ ] Vitesse ×1,10
- [ ] Style TikTok, dynamique, cuts
- [ ] **Minimum 9 à 12 créatives, 3 angles différents, pour démarrer**

Checklist par créative :
- [ ] Hook fort dans les 3 premières secondes
- [ ] Bénéfice clair
- [ ] CTA explicite
- [ ] Compliance vérifiée (pas de promesse chiffrée sur durée, pas d'avant/après brut)

> 📖 `03-marketing-copy/creatives-ads.md`

## 4.3 — Ad copies

- [ ] 5 textes primaires
- [ ] 5 headlines
- [ ] 5 descriptions

> 📖 `07-templates/prompts-ia.md` § 2

## 4.4 — Configurer la campagne

| Niveau | Réglage |
|---|---|
| Campagne | Normale, objectif **Ventes**, budget **CBO** |
| Adset | **Broad** (pays uniquement), **Dynamic creative ON** |
| Pixel | Selon budget (voir tableau ci-dessous) |
| Exclusions | Taïwan, Hong Kong |

**Choix de l'événement de conversion :**

| Budget | Événement |
|---|---|
| 100-150 €+/jour, expérimenté | **Purchase** |
| 30-50 €/jour | **InitiateCheckout** |
| Produit très cher, peu de checkouts | **Lead** |

**Règle : 20 à 50 déclenchements de pixel par semaine minimum.**

## 4.5 — Lancer

- [ ] Budget testing : 30-50 €/jour minimum (optimal : 100-150 €/jour)
- [ ] Laisser tourner **48 h minimum** avant de juger
- [ ] ❌ Ne pas créer de campagne de testing de créas si < 1 000 €/jour de spend
- [ ] Ajouter une pub image clean à **2 €/jour** en permanence (solidité du compte)

## 4.6 — Ajouter la campagne CONTRÔLE (dès 100 €/jour de spend)

```
Campagne dédiée · 3-5 % du spend · objectif ENGAGEMENT
Sur l'ADS bestseller · CTA "like / commente" · aucun lien externe
→ -15 à -20 % de CPM
```

**✅ Livrable Phase 4 :** campagne live, 9-12 créatives, données qui rentrent.

# ═══ PHASE 5 — BACKEND (LE PROFIT) ═══

> Le front-end est souvent à l'équilibre. **50-60 % du CA vient d'ici.**

## 5.1 — Séquence de retargeting 7 jours (structure CEO)

| Jour | Levier |
|---|---|
| J1 | Encourager les rêves |
| J2 | Excuser les échecs |
| J3 | Réduire les peurs |
| J4 | Confirmer les doutes |
| J5 | Jeter la pierre à l'ennemi |
| J6 | Closing — urgence |
| J7 | Closing — urgence finale (**3 mails** : 16h / 20h / 23h) |

- [ ] Objet + expéditeur travaillés pour chaque mail
- [ ] Bouton CTA visible dans **chaque** mail
- [ ] 200-400 mots par mail

## 5.2 — Les 3 automatisations

- [ ] **Séquence 1** : opt-in landing page → offre 1
- [ ] **Séquence 2** : panier abandonné → relance checkout
- [ ] **Séquence 3** : acheteur → **exclu de la séquence 1**, envoyé sur VSL 2

## 5.3 — Délivrabilité

- [ ] DNS paramétré sur le nom de domaine
- [ ] Base filtrée (couper ceux qui n'ouvrent pas depuis 90 jours)
- [ ] Max 3 spam words par mail

## 5.4 — Newsletter (après la séquence)

- [ ] Jour et heure fixes
- [ ] Contenu de valeur + storytelling
- [ ] **Un CTA dans chaque envoi**

> 📖 `03-marketing-copy/emailing.md` · `07-templates/objets-email.md`

**✅ Livrable Phase 5 :** 3 automatisations actives + newsletter démarrée.

# ═══ PHASE 6 — OPTIMISATION (∞) ═══

> **LTV ↑ , CPA ↓.** C'est le vrai métier. Tout le reste était du setup.

## 6.1 — Le rituel quotidien

```
1. Tracker TOUTES les stats, TOUS les jours
2. Identifier la métrique la plus faible
3. Formuler des hypothèses
4. A/B tester UNE variable à la fois
5. Garder ce qui gagne, itérer
```

## 6.2 — Ordre de priorité

```
1. HEADLINE de la VSL        ← 30 secondes de travail, plus gros levier
2. LEAD de la VSL            ← vrai travail, gros impact
3. CRÉATIVES                 ← le 20/80 du CPA
4. BUMP pré-coché            ← 5 minutes, gain instantané
5. UPSELL (s'il manque)      ← gain instantané
6. SÉQUENCE EMAIL 7 jours    ← le profit net
7. Le reste
```

## 6.3 — Feedback loop produit

- [ ] Sonder les clients
- [ ] Appliquer leurs retours
- [ ] Injecter les profits dans l'amélioration du produit
- [ ] **Vendre dans le produit** (niveau suivant de la value ladder)

> 📖 `05-funnel/optimisation-checklist.md` *(les 6 checklists détaillées)*

# ═══ RÉCAPITULATIF EXPRESS ═══

```
0. Niche + canal + awareness + format
1. Avatar (matrice, ennemi, objections, 20-50 bénéfices) + Offre (8 composantes) + MVP
2. Headline → Lead (1 des 10) → Body (structure CEO 11 blocs) → Closing (3 outils)
3. Setup FB + funnel + pixels
4. 20-50 angles → 10×10×10 créatives → Broad + CBO → lancer 48h
5. Séquence 7 jours (structure CEO) + 3 automatisations + newsletter
6. Tracker, tester, itérer — pour toujours
```

## Les 5 erreurs qui tuent un funnel

1. **Sauter la Phase 1.** Pas d'avatar = pas de copy = pas de vente.
2. **Parler du produit au lieu du bénéfice.** L'erreur n°1.
3. **Pas d'urgence.** Le prospect n'achète pas maintenant → jamais.
4. **Une seule créative.** Le funnel d'ads a besoin de volume et d'angles.
5. **Pas d'emailing.** Tu laisses 50-60 % de ton CA sur la table.
