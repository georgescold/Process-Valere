# L'emailing — où se trouve le profit net

> **50 à 60 % du CA vient de l'emailing.** C'est ce qui produit le profit net.
> Le front-end (ADS → VSL → achat) est souvent à l'équilibre. Le back-end fait l'argent.

## Le principe premier

> **L'emailing, c'est recontacter quelqu'un gratuitement.**

Tu as payé pour acquérir ces gens. Maintenant tu peux les recontacter à l'infini
pour le prix de ton hébergeur. C'est le meilleur ratio du business.

---

## Où l'emailing s'insère

```
ADS → LP → VSL → BDC → Upsell → TY page
       │     │            │
       └─────┴────────────┴──→ CAPTURE D'EMAIL
                                     │
                    ┌────────────────┴──────────────┐
                    ↓                               ↓
            RETARGETING (auto)              NEWSLETTER (récurrent)
            7-14 jours sur la               contenu + CTA
            MÊME offre                      chaque semaine
                    │
                    ↓
            RETARGETING sur VSL 2, 3, 4…
```

3 sources d'email : opt-in landing page, réservation d'appel, achat.

---

## Les 4 objectifs d'un email (dans l'ordre)

| # | Objectif | Ce qui le pilote |
|---|---|---|
| 1 | **Délivrer** | DNS paramétré, base filtrée, réputation |
| 2 | **Ouvrir** | Objet **+ expéditeur** |
| 3 | **Cliquer** | Corps du mail + CTA |
| 4 | **Acheter** | Le système entier (mail + page de destination) |

⚠️ Le plus beau mail du monde ne sert à rien s'il ne délivre pas.

**Délivrer** = arriver dans la boîte principale. Pas dans "Promotions", pas dans "Spam".
- Paramétrer le DNS du nom de domaine
- **Filtrer sa base** : si quelqu'un n'a pas ouvert depuis 90 jours, arrête de lui
  envoyer (ou bascule-le sur un autre nom de domaine)

**L'expéditeur compte autant que l'objet.** "Cadeau pour Victor" envoyé par *Valère*
s'ouvre. Le même objet envoyé par *Asana* ne s'ouvre pas.

## Les 3 stratégies d'emailing

### 1. NEWSLETTER ⭐ 9/10 — la stratégie recommandée

Envoi récurrent à jour et heure fixes.

| ✅ Avantages | ❌ Inconvénients |
|---|---|
| Engageant — les gens l'attendent | Il faut créer du **bon** contenu |
| Branding long terme | Perte d'intérêt possible de l'audience |
| **Revendable** (l'actif a une valeur) | Pas de droit à l'erreur (2-3 mauvais mails = désabonnements) |
| Revenu stable et linéaire | |
| Conversion très élevée (bâtit la trust) | |
| Crée une communauté | |
| **Taux de désabonnement faible** | |

### 2. SÉQUENCE DE RETARGETING ⭐ 8/10 — obligatoire

Automatisation déclenchée après un opt-in.

| ✅ Avantages | ❌ Inconvénients |
|---|---|
| **Automatique** — écrit une fois, tourne toujours | Peu de relation créée |
| Conversion très élevée | Taux de désabonnement plus élevé |
| Ultra personnalisable (revenus, sexe, offre) | |
| Rapide à écrire (on réutilise la VSL) | |
| **Augmente la LTV** | |

Durée : 7 à 14 jours. Fréquence : 1 à 2 emails/jour.

### 3. EMAIL PAGE DE VENTE ⭐ 7/10 — le format Agora

Un email **très long** — l'équivalent de 5-6 pages Google Doc — qui est en réalité
une page de vente complète. Le lien renvoie **directement sur le bon de commande**.

```
HOOK → structure complète de vente → PRIX ANNONCÉ → lien = BON DE COMMANDE
```

Le but : **closer le prospect directement dans l'email**, sans page intermédiaire.
C'est ce que fait Agora, et ça marche très bien.

⚠️ Demande un excellent niveau de copywriting. Ce n'est pas un format de débutant.

### 4. SPAM (3 mails/jour) ⭐ 3/10 — à éviter

Argent court terme, mails très courts et simples.
Désavantages : pas de relation, désabonnements massifs, LTV faible, image scam,
délivrabilité qui s'effondre.

> "Ça a peut-être marché un moment. Ça ne marche plus aujourd'hui."

---

> **La meilleure approche : un mélange des trois** (relation + page de vente,
> et le spam jamais). Une séquence dure typiquement 7 à 10 jours, à raison de
> 1 à 3 mails par jour sur la même offre.

## Pourquoi le spam ne vaut pas le coup — le raisonnement

Ce n'est pas une question d'éthique, c'est une question de rationalité :

> Ton job, c'est de faire rentrer de l'argent. Alors : qu'est-ce qui rapporte le
> plus — envoyer 3 mails de 3 lignes par jour, ou bâtir une relation qui dure et
> gagner plus longtemps ?
>
> **Si le spam rapportait plus, on ferait du spam.** Ce n'est pas le cas.

Le corollaire : l'argent d'aujourd'hui vaut moins que plus d'argent dans un mois.
Ce n'est pas de l'abondance, c'est du calcul.

## Combiner les deux

```
J1-J7   : Séquence de retargeting automatique (offre 1)
J8-J14  : Séquence de retargeting (offre 2)
J15+    : Newsletter récurrente
```

Ou : brander la séquence automatique **en tant que** newsletter.

**La séquence de 7 jours est OBLIGATOIRE. On ne fait aucune newsletter avant.**

## Les 3 séquences de retargeting à créer

Trois automatisations distinctes selon l'état du prospect :

| # | Déclencheur | Ce qu'on envoie |
|---|---|---|
| 1 | A opt-in sur la landing page | Séquence complète sur l'offre 1 |
| 2 | Panier abandonné (arrivé au bon de commande sans acheter) | Séquence de relance checkout |
| 3 | **A acheté** | ❌ Exclu de la séquence 1 → envoyé directement sur la VSL 2 |

⚠️ Ne jamais reproposer le même produit à quelqu'un qui l'a déjà acheté.

## LA STRUCTURE 7 JOURS (structure CEO)

C'est **une VSL étalée sur 7 jours**. Un jour = un levier.

| Jour | Levier | Objet type |
|---|---|---|
| **J1** | Encourager les rêves | "Une Lamborghini pour %FIRSTNAME%" |
| **J2** | Excuser les échecs | "Tu as perdu 1 million ce matin" |
| **J3** | Réduire les peurs | — |
| **J4** | Confirmer les doutes | — |
| **J5** | Jeter la pierre à l'ennemi | — |
| **J6** | **Closing** — urgence / rareté | "Plus que 24h" |
| **J7** | **Closing** — urgence finale | "C'est maintenant %FIRSTNAME%" |

**Le dernier jour, envoyer 3 mails :** 16h / 20h / 21h (ou 23h).
Personne ne t'en voudra. C'est le moment où tu es censé gagner de l'argent.
Un désabonnement à ce stade = quelqu'un qui n'aurait jamais acheté.

**Toujours mettre le bouton CTA visible dans chaque mail de retargeting.**

| Trafic | Destination |

| Chaud / bas de funnel | Bon de commande direct |
| Gros bon de commande / high ticket | VSL (avec bouton) |

## Le corps du mail

**Un mail = un lead.** Reprends les 10 types de leads
(`03-marketing-copy/leads-et-hooks.md`), ajoute un CTA, éventuellement un mini-closing.

Formule qui ne peut pas rater :
```
1 objet (parmi les 12 types)
+ 1 lead (parmi les 10 types)
+ 1 CTA
= 8/10 en copywriting
```

---

## Notes en vrac

- **Longueur** : entre 200 et 400 mots par mail (repère, pas une règle)
- **Heure d'envoi** : entre 16h et 20h30 si un mail/jour. Si deux : midi + soir.
  Si trois : matin + midi + soir. Pas de mail avant 8h ; 4h du matin = mauvais.
- **Segmenter ses listes** — obligatoire
- **L'argent n'est pas dans la relation.** L'argent est dans le **bénéfice** et la
  **trust**. La relation ne sert qu'à bâtir la trust.
- **Il y a un CTA dans chaque mail.** Pas d'exception.
  *"Une pièce de contenu sans call to action est une pièce de contenu gâchée."*
- **Storytelling + valeur en même temps** : raconte une histoire ET apporte un
  conseil dans le même mail.
- **Outils** : Systeme.io, ActiveCampaign, MailChimp. Amazon SES pour les gros volumes.
